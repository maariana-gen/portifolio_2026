Portfólio pessoal desenvolvido com **HTML, CSS e JavaScript**, com o objetivo de apresentar minha trajetória, meus projetos e minhas formas de contato de maneira moderna, responsiva e organizada.

O projeto consome dados da **API do GitHub**, exibindo informações do perfil e repositórios de forma dinâmica.

---

## Funcionalidades

- Estrutura desenvolvida com **HTML semântico**
- Interface responsiva para desktop, tablet e mobile
- Estilização com **CSS**, utilizando variáveis, animações e efeitos visuais
- Integração com a **API do GitHub**
- Exibição de projetos em carrossel com **Swiper.js**
- Formulário de contato com validação no frontend
- Página de confirmação após envio da mensagem
- Menu fixo e navegação com rolagem suave

## Como executar localmente

Clone o repositório:

```bash
git clone https://github.com/maariana-gen/portifolio_2026.git
```

Acesse a pasta do projeto:

```bash
cd portifolio_2026
```

Abra o projeto no VS Code:

```bash
code .
```

Depois, abra o arquivo `index.html` com a extensão **Live Server**.
